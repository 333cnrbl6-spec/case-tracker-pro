# Sales Outreach Launch Checklist

## Pre-Launch (Week 1)

- [ ] Segment contact list:
  - [ ] Managing Partners (200 contacts)
  - [ ] Compliance Officers (150 contacts)
  - [ ] Fee Earners (500 contacts)
  
- [ ] Customize email templates:
  - [ ] Partner version (value focus)
  - [ ] Compliance version (risk focus)
  - [ ] Fee Earner version (time-savings focus)

- [ ] Set up tracking:
  - [ ] UTM parameters for all links
  - [ ] Email tracking (opens, clicks)
  - [ ] Landing page analytics

- [ ] Prepare case studies:
  - [ ] Write 2-3 anonymized success stories
  - [ ] Get quotes from beta customers
  - [ ] Create PDF case study sheets

- [ ] LinkedIn strategy:
  - [ ] Create founder post about launch
  - [ ] Schedule weekly tips on RICS/settlements
  - [ ] Connect with 20 target partners per week

- [ ] Partnership outreach:
  - [ ] Identify Clio/Rocket Matter admins
  - [ ] Draft partnership proposal
  - [ ] Schedule partnership calls

## Week 1-2: Soft Launch

- [ ] Send email #1 to warm leads (existing contacts, beta users)
  - Target: 50 emails
  - Expected response: 8-12%

- [ ] Monitor inbound:
  - [ ] Set up support queue
  - [ ] Create FAQ for common questions
  - [ ] Log all objections

- [ ] Quick wins:
  - [ ] Book 3-5 discovery calls
  - [ ] Get 1-2 testimonials
  - [ ] Generate 2-3 case studies

## Week 3-4: Main Campaign

- [ ] Cold email campaign #1 (value stack):
  - Target: 100 partners
  - Expected response: 8 replies
  - Follow-up: Day 5

- [ ] Cold email campaign #2 (compliance angle):
  - Target: 75 compliance officers
  - Expected response: 7 replies
  - Follow-up: Day 5

- [ ] Cold email campaign #3 (efficiency angle):
  - Target: 150 fee earners
  - Expected response: 18 replies
  - Follow-up: Day 7

- [ ] LinkedIn strategy in full swing:
  - 2 posts per week
  - 30 new connections per week
  - 5 cold DMs per week

- [ ] Track metrics:
  - [ ] Email open rate (target: 25%+)
  - [ ] Click-through rate (target: 3%+)
  - [ ] Reply rate (target: 8-12%)
  - [ ] Trial signup rate (target: 20% of replies)

## Month 2: Scale What Works

- [ ] Double down on highest-converting channels
  - [ ] If cold email partner version works: 200 more
  - [ ] If LinkedIn works: 50 new connections/week
  - [ ] If partnerships work: 3 more partnership calls

- [ ] Referral program:
  - [ ] Offer existing customers £500 for each referral
  - [ ] Create referral link template
  - [ ] Email all current customers with offer

- [ ] Content marketing:
  - [ ] Publish 1 blog per week on RICS/settlements/AI
  - [ ] Share on LinkedIn
  - [ ] Repurpose as email sequences

- [ ] Sales team efficiency:
  - [ ] Document best discovery call script
  - [ ] Create reusable pitch deck
  - [ ] Build objection playbook

## Ongoing (Every Week)

- [ ] Monday:
  - [ ] Review last week's metrics
  - [ ] Plan this week's outreach
  - [ ] Identify 50 new warm contacts

- [ ] Wednesday:
  - [ ] Send main email batch
  - [ ] Post on LinkedIn
  - [ ] Make 5-10 discovery calls

- [ ] Friday:
  - [ ] Log all replies and objections
  - [ ] Book follow-up calls
  - [ ] Update contact status in CRM

## Success Metrics

| Metric | Target | Month 1 | Month 2 |
|--------|--------|---------|---------|
| Trial Signups | 50 | ✓ | 100+ |
| Demo Calls Booked | 20 | ✓ | 40+ |
| Conversions to Paid | 8 | ✓ | 20+ |
| MRR Growth | +£4K | ✓ | +£8K |
| NPS | 40+ | ✓ | 45+ |

## Red Flags to Watch

- Email open rate drops below 20% → Rotate subject lines
- Reply rate below 5% → Adjust messaging or audience
- Trial signups slow down → Check onboarding flow
- No conversions after 10 demos → Fix demo script or product
- Support load overwhelming → Hire support person

## Quick Wins for Week 1

1. **Email 5 existing beta users** asking for testimonials (2 will respond)
2. **Post on LinkedIn** about launch (100+ views, 5-10 DMs)
3. **Book 2 discovery calls** with warm contacts (both will convert)
4. **Get 1 partnership inquiry** from competitor watchers
5. **See 10+ trial signups** from organic traffic

These win fast and give momentum.
